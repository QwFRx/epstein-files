# Система автоматизации школьной столовой 🏫🍽️

Профессиональное приложение для управления школьным питанием, заказами и складским учётом.  
Проект состоит из **Backend + Frontend** и предназначен для учеников, поваров и администраторов.

## 🚀 Ключевые возможности

- Авторизация через **JWT** + хеширование паролей (**bcrypt**) 🔐  
- Ролевая модель: **Student / Cook / Admin** 👥  
- Учёт ингредиентов и автоматическое списание при заказах 📦  
- Проверка аллергенов по профилю ученика ⚠️  
- Отчёты по выручке и остаткам 📊  
- API с интерактивной документацией (**Swagger / OpenAPI**) 🧭

## 🐍 Установка и запуск — Backend

1. Клонировать репозиторий:

```bash
git clone https://github.com/QwFRx/epstein-files.git
cd epstein-files
````

2. Создать и активировать виртуальное окружение:

```bash
python -m venv .venv
# Linux / macOS
source .venv/bin/activate
# Windows
.venv\Scripts\Activate
```

3. Установить зависимости:

```bash
pip install -r requirements.txt
```

4. Заполнить базу тестовыми данными:

```bash
python -m backend.seed
```

5. Запустить сервер:

```bash
python -m uvicorn backend.main:app --reload
```

Backend будет доступен по адресу:
👉 `http://127.0.0.1:8000`
👉 Swagger: `http://127.0.0.1:8000/docs`

---

## ⚛️ Установка и запуск — Frontend

1. Перейти в папку фронта:

```bash
cd frontend
```

2. Установить зависимости:

```bash
npm install axios lucide-react clsx tailwind-merge
```

3. Запустить dev-сервер:

```bash
npm run dev
```

Открыть в браузере:
👉 `http://localhost:5173`

## 🔗 Настройка адреса API для фронта

### Рекомендуемый способ (через `.env`)

В папке `frontend/` создать файл `.env`:

```
VITE_API_URL=http://127.0.0.1:8000
```

В `src/api.js`:

```js
export const API_BASE =
  import.meta.env.VITE_API_URL || 'http://127.0.0.1:8000';
```

⚠️ После изменения `.env` обязательно перезапустите `npm run dev`.
